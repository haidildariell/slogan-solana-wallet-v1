This entry writes one slogan for a Solana wallet agent to `/output/entry.txt`.

## Slogan

> Your Solana wallet, awake while you sleep: it signs, swaps, and sends before your coffee cools.

## Run

```sh
python3 main.py
```

The program validates the slogan first (one line, at most 20 words,
1–140 characters) and then writes it to `/output/entry.txt`.
